## Applied Consulteam direction

These product-specific decisions override the generic generator suggestions below.

- **Product:** a Russian-language agency workspace for international student admissions. Keep existing API contracts, authentication, Instagram/WhatsApp messaging, consultations, student profiles, sales, and admission stages.
- **Style:** use the generator's Minimalism / Swiss direction, clear typographic hierarchy, disciplined spacing, flat surfaces, and restrained interaction states. The generator's marketing-page pattern does not apply to the authenticated workspace.
- **Brand:** preserve the supplied `Consulteam_Logo.jpg` without redrawing or recoloring it. Use navy `#283876` for primary actions and `#1c2856` for the sidebar, with white surfaces on `#f5f6fa`. Supporting text uses `#647087`; green identifies successful admissions and confirmations.
- **Typography:** locally bundled Inter, including Latin, Cyrillic and extended Cyrillic. Use 14–16 px for message/form body text, 12–13 px for supporting labels, and 23–31 px for page headings. Small brand/section labels are decorative metadata. No font requests are sent to Google at build or runtime; the Inter license is in `frontend/public/fonts/OFL.txt`.
- **Layout:** persistent labeled desktop navigation, breadcrumb header, focused content area, and a mobile drawer. The overview uses real API metrics, admissions-stage counts, upcoming consultations, and recent conversations. Never seed fabricated business data into the app.
- **Inbox:** visible search, open/unread/AI/unassigned filters, channel filter, conversation list, message history, quick replies, and student profile dialog. On phones, move between list and conversation with a back button. Unsent text is preserved when message delivery fails.
- **Mobile:** student and consultation tables reflow into labeled cards. The Kanban board scrolls within its own region. Keep the document within the viewport.
- **Accessibility:** semantic links/buttons, associated form labels, visible keyboard focus, skip link, labeled icon buttons, pressed/expanded state, native profile dialog with Escape dismissal, and reduced-motion support.
- **Loading and failures:** show explicit loading, empty and error states, with retries. Unavailable statistics display a dash. Do not claim that integrations are connected without a real status response.

## Style Guidelines

**Style:** Minimalism & Swiss Style

**Keywords:** Clean, simple, spacious, functional, white space, high contrast, geometric, sans-serif, grid-based, essential

**Best For:** Enterprise apps, dashboards, documentation sites, SaaS platforms, professional tools

**Key Effects:** Subtle hover (200-250ms), smooth transitions, sharp shadows if any, clear type hierarchy, fast loading

### Page Pattern

**Pattern Name:** Product Demo + Features

- **Conversion Strategy:** Use an interactive demo only when it explains value better than static media. Provide captions, transcript, visible play/pause controls, and a non-video fallback; do not autoplay under reduced motion. Pause media when offscreen or hidden and keep the final product state available as static content.
- **CTA Placement:** Video center + CTA right/bottom
- **Section Order:** Hero > Product video/mockup (center) > Feature breakdown per section > Comparison (optional) > CTA

---

## Anti-Patterns (Do NOT Use)

- ❌ Excessive decoration
- ❌ Complex shadows
- ❌ 3D effects

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — Use SVG icons (Heroicons, Lucide, Simple Icons)
- ❌ **Missing cursor:pointer** — All clickable elements must have cursor:pointer
- ❌ **Layout-shifting hovers** — Avoid scale transforms that shift layout
- ❌ **Low contrast text** — Maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — Always use transitions (150-300ms)
- ❌ **Invisible focus states** — Focus states must be visible for a11y

## Pre-Delivery Checklist

Before delivering any UI code, verify:

- [ ] No emojis used as icons (use SVG instead)
- [ ] All icons from consistent icon set (Heroicons/Lucide)
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard navigation
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] No content hidden behind fixed navbars
- [ ] No horizontal scroll on mobile
